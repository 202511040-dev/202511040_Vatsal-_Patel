GloVe Pretrained Embeddings for Movie Text Prediction

PROJECT SUMMARY

This project explores the use of pretrained GloVe word embeddings for text-based prediction tasks using movie metadata. Two main predictive tasks were implemented:

Regression to predict movie ratings

Multi-label classification to predict movie genres

Additionally, text analysis was performed to identify frequent and genre-indicative words.

Only the required columns were used, and each text column was evaluated separately without concatenation.
